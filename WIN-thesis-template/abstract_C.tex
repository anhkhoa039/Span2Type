\addcontentsline{toc}{chapter}{摘要}
\begin{center}
    \textbf{\large 摘要}
\end{center}

在特定領域中，命名實體識別（Named Entity Recognition, NER）需要耗費大量人力進行資料標註，且須預先定義實體類型。本論文探討\textbf{開放世界命名實體識別（Open-world NER）}：在不依賴任何目標領域監督的情況下，從未標註文本中偵測實體提及，並自動發掘與命名潛在的實體類型。

基於OWNER框架，我們提出\textbf{Span2Type}，包含三項針對性改進。首先，我們以多視角分治轉移（DTrans）編碼器~\cite{zhang-etal-2024-dtrans}取代BIO提及偵測器，聯合訓練BIO、起始-結束（Start-End）及連繫-斷開（Tie-Break）三個解碼頭，提升跨領域的跨度召回率。其次，我們引入軟提示實體編碼：在填空式BERT模板前附加可訓練的虛擬詞元，並以\texttt{[MASK]}位置的嵌入向量作為具類型鑑別力的表徵用於分群。第三，我們提出基於最大邊際相關性（MMR）的範例選取策略，以多樣化的分群證據查詢遮蔽語言模型（MLM）或本地大型語言模型，生成簡潔且人類可讀的類型標籤。

在CrossNER五個目標領域的評估中，Span2Type達到平均AMI 61.4，較OWNER基準提升12.0分，分群命名的BERTScore-F1為0.924。

\noindent\textbf{關鍵字：}開放世界命名實體識別（Open-world Named Entity Recognition）；非監督式NER（Unsupervised NER）；多視角跨度偵測（Multi-view Span Detection）；軟提示實體分類（Soft Prompt Entity Typing）；分群命名（Cluster Naming）
